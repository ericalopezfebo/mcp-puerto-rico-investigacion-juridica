# Confidentiality and professional-use policy

This public repository contains software, prompts, or reference material. It is not a secure client portal and does not create an attorney-client relationship.

## Never submit client information to GitHub

Do not place in issues, pull requests, discussions, commits, tests, screenshots, logs, workflow artifacts, or sample files:

- names or facts that identify a client, witness, employee, minor, victim, juror, or adverse party;
- court filings or agency records that are sealed, confidential, privileged, or not already lawfully public;
- legal strategy, communications, work product, credentials, access tokens, calendar data, email contents, or document metadata;
- real matter numbers combined with nonpublic facts.

Use purpose-built synthetic data. Redaction is not the same as anonymization; combinations of facts can permit re-identification.

## Duties of a lawyer using this project

The lawyer remains responsible for competence, technological competence, confidentiality, conflicts, supervision, accuracy, deadlines, client communication, and the final work product. Review current primary authority and all generated output independently. Do not represent an automated result as legal advice from the maintainer.

Before processing client information, evaluate the deployment, vendors, data location, retention, subprocessors, access controls, incident response, backups, deletion, and whether client consent or disclosure is required. Prefer local processing when the matter is sensitive.

## Security incidents

Do not disclose a vulnerability publicly when the report could expose confidential information. Contact the maintainer privately through GitHub's private vulnerability-reporting feature when enabled. If unavailable, open a content-free issue requesting a private channel.

## Production status

A public release or passing test suite is not a certification of compliance, confidentiality, fitness for a particular matter, or perfect accuracy. Repository-specific documentation may impose stricter restrictions.
